### 02 · [MAE-ViT: Label-Efficient Semantic Segmentation](https://github.com/MD-IKRAM169/mae-vit-label-efficient-segmentation)

### 03 · [CO₂ Emissions & Atmospheric Pressure Analytics](https://github.com/MD-IKRAM169/CO2-Emissions-Atmospheric-Pressure-Analytics)

### 05 · [Social-Media Language Analysis & Feature Selection](https://github.com/MD-IKRAM169/Social-Media-Language-Analysis-and-Feature-Selection)
**Text Mining · Linguistic Features · R · Exploratory Statistics**

A retrospective academic research project exploring linguistic features in historical social-media text using LIWC and variable-subset selection in R. This is **exploratory research**, not a validated individual risk-prediction or clinical tool.

### 06 · [Data Mining Project](https://github.com/MD-IKRAM169/Datamining-Project)
**WEKA · Classification · Clustering · scikit-learn**

Academic investigations of supervised and unsupervised learning, including classifier comparisons and clustering techniques. The repository preserves original coursework reports alongside separate, modern Python demonstrations using synthetic data.
